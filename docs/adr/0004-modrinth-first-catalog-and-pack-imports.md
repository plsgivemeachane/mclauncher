# Modrinth-first catalog with portable pack imports

The first modding release provides integrated Modrinth browsing and installation alongside Modrinth `.mrpack` and CurseForge exported-pack ZIP imports. The player prefers integrated discovery to an import-only product, but integrated CurseForge browsing is deferred until API access is established rather than making that access a prerequisite for all mod support. Imported packs must retain their provider identity so future updates can follow their source.
