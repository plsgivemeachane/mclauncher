# Minecraft home screen and explicit instance navigation

The player approved Home / Instances / Browse navigation, a Minecraft screenshot background, Minecraft release/news cards, a secondary launcher changelog, and compact bottom launch controls. This supersedes ADR 0002's flat-landscape choice, feed exclusion, and restriction against a separate instance management screen: modpack discovery and multiple named instances now justify dedicated navigation. Retain the single Play action that owns preparation and launch, automatic vanilla instances, and existing saved setups.

Bundle a background, permit a custom image, and cache news so the home screen remains useful offline and fetching content never gates launching. TLauncher is a reference for the player journey rather than a source of assets to copy.
