# Minecraft Launcher

A launcher for regular players to install Minecraft Java Edition and start offline sessions.

## Language

**Launcher**:
The desktop application players use to install Minecraft and start the game.
_Avoid_: Modding tool, development environment

**Offline session**:
A Minecraft play session using a local player identity without an authenticated Microsoft/Minecraft account session. The term describes the identity, not whether the computer has an internet connection.
_Avoid_: Non-online version, separate offline edition

**Vanilla Minecraft**:
Minecraft without third-party mods or mod loaders.
_Avoid_: Unmodded modpack

**Instance**:
A separate playable Minecraft setup with its own game version, worlds, settings, and screenshots.
_Avoid_: Account, session

**Managed Java runtime**:
A Java runtime downloaded and maintained by the launcher for running Minecraft.
_Avoid_: System Java

**Local player identity**:
The player identity used for offline sessions, determined by the saved username and stable for that username across launches. Changing the username changes this identity.
_Avoid_: Microsoft account, authenticated account
